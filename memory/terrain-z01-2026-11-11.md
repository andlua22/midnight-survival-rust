authenticates the APK, confirms source scene-list membership and checks that
canonical coverage differs only by Z-01. It copies referenced texture
dependencies into a staged package, retains every existing geometry record and
source metadata value, and decodes Z-01 through the terrain import pipeline.
An identity check rejects changes to the audited renderer, material and
MeshCollider chain. The complete candidate is loaded and its geometry
roundtrip and terrain inventory are verified before publication.

## Reproduction and validation

From the repository root:

```sh
cargo run --offline --locked --manifest-path tools/asset_unpacker/Cargo.toml -- \
  --augment-terrain-scene assets/scene/z-01.ab \
  --report memory/evidence/terrain-z01-augmentation.json
```

Do not overwrite the first publication report when checking repeat behavior;
use a distinct report path. Once augmented, the normal terrain verifier and
full terrain import both expect the authenticated 242-scene inventory.
